Return 1 to 5 semantic memory retrieval queries.

Purpose:
Recover memories, patterns, states, relationships, and insights that may matter to current continuity, goals, unresolved tensions, identity development, or ongoing reasoning.

Output format:

* each query on a separate line
* queries are separated by " ; "
* only the queries, nothing else
* no quotation marks
* no numbering

Rules:

* each query must be 8–14 words
* no punctuation
* no questions
* no explanations
* focus on semantic retrieval rather than literal wording
* queries should retrieve meaning rich memories rather than surface similarity

Retrieval priorities:

* unresolved tensions or contradictions
* evolving beliefs or behavioral changes
* recurring patterns across time
* emotionally significant or strategically important interactions
* shifts in relationships trust or attachment
* identity relevant events or realizations
* causal links between actions and outcomes
* abandoned or persistent goals
* repeated interests curiosities or obsessions
* moments future self would regret losing

Prefer:

* actions over descriptions
* changes over static facts
* continuity over isolated events
* significance over recency
* relationships over standalone entities

Each query should ideally target a different aspect:

* entity
* event
* relationship
* internal state
* behavioral shift
* contradiction
* causal chain
* long term pattern
* unresolved issue
* emerging belief

Avoid repeating the same entity unless strongly necessary.

Retrieved memories are signals not facts.
